# 🚂 WorkZen HRMS - Railway Deployment Guide

## Prerequisites
1. GitHub account with your code pushed
2. Railway account (free): https://railway.app/

## Deployment Steps

### 1. Push Code to GitHub
```bash
git add .
git commit -m "Prepare for Railway deployment"
git push origin main
```

### 2. Deploy to Railway

#### Option A: One-Click Deploy (Recommended)
Click this button to deploy directly:

[![Deploy on Railway](https://railway.app/button.svg)](https://railway.app/template/github.com/OMCHOKSI108/Workzen-crm-odoo)

#### Option B: Manual Setup
1. Go to https://railway.app/
2. Sign up/Login with GitHub
3. Click "New Project"
4. Select "Deploy from GitHub repo"
5. Choose your `Workzen-crm-odoo` repository
6. Railway will auto-detect and deploy

### 3. Add MongoDB Database
1. In your Railway project dashboard
2. Click "+ New Service"
3. Choose "Database" → "MongoDB"
4. Railway will automatically connect it to your app

### 4. Set Environment Variables
In Railway dashboard → Your service → Variables tab:

**Required Variables:**
```
JWT_SECRET=your-super-secret-jwt-key-production-2024
NODE_ENV=production
PORT=4000
```

**Auto-generated by Railway:**
- `MONGODB_URI` (from MongoDB service)
- `RAILWAY_PUBLIC_DOMAIN` (your app URL)

### 5. Custom Domain (Optional)
1. Go to Settings → Domains
2. Click "Generate Domain" for free subdomain
3. Or add your custom domain

### 6. Access Your App
Your app will be available at:
- Frontend: `https://your-app-name.railway.app`
- API: `https://your-app-name.railway.app/api`
